# AI 文档助手

Streamlit 试运行：参与者钉钉登录、项目接入申请、提案提交与管理员审核发布。当前固定为 level tunning。

## 管理首页

管理员钉钉登录后使用四个 Tab：项目权限管理（参与者、申请与授权状态、批准/续期/撤销）、提案审核（列表、状态与关键词筛选、详情、逐份批准）、创建提案（管理员草稿）、运行与备份（连接诊断及手动备份）。权限批准只允许提交修改提案，不授予正式文档直接编辑或审核权。

列表支持待审核、审批执行中需核对、已发布；已进入执行或发布的详情只读，不能再次作为待审核提案批准。显示元信息是定位缓存，详情仍核对钉钉原文及落库指纹。

## 其他 Agent 提交页面

提交入口 `https://aitest-kltimq4ak9guq9eijbhz3j.streamlit.app/?page=submit`，不经过审核人的诊断密码，不提供批准、正式发布或任意目标库写入功能。Streamlit 平台的应用访问限制仍需单独允许参与者访问。

参与者本人完成钉钉 OAuth 登录后申请项目接入，管理员在“项目权限管理”批准有期限的仅提交权限。无须领取提交凭据或诊断密码。服务核验钉钉 unionId，并在每次提交时重新核验签名项目授权与撤销记录。旧凭据模块仅兼容历史记录，当前页面不使用或签发旧 token。不要删除或改写授权/撤销原始记录。

Agent 可自动操作该网页填写表单，或上传 JSON 后提交。schema_version=1；project_id=`PRJ-4a5cce5e-e785-57e2-833a-010a6f9394d2`；request_id 使用小写标准 UUID，重试保持不变，修改正文必须换新请求 ID。业务字段为 module/title/kind/reason/content；可选 document_id/base_revision_id/code_bindings。禁止提交审批人、批准状态、目录、知识库、凭据等未知字段。

服务以钉钉认证身份确定提交人，校验项目权限、目标正式文档归属、基线、正文大小、UUID 与代码 SHA，写入审核库，回读后返回提案编号、内容指纹与链接。请求 ID 和内容绑定，使用确定性提案 ID 防止云端恢复后重复创建。创建结果不确定时停止，不换新 ID 重放。

审核人在原入口刷新恢复列表，加载提案后决定是否批准。草稿身份字段与提交回执会显示在审核页面。此入口属于浏览器自动操作流程，尚不是 HTTP/MCP API；日常中间记录目前也按待审提案存储，不自动转正式。

三库路由：新提案、审批、沟通/修正与恢复凭据进入审核库；正式版本及版本变更进入原正式库；备份库使用最新完整副本与可逆历史 diff。旧历史位置兼容读取。每日备份 workflow 尚未启用凭据配置，不因代码存在就声称任务运行。

登录后自动扫描项目管理的四个钉钉目录（完整分页），校验签名恢复凭据及对应正文，重建本地 SQLite，显示最近 100 条提案。可在新会话或云端重建后加载待审正文。已进入审批或发布的提案不会被当作新的待审项批准；恢复不自动执行发布。

现支持已认证操作人保存独立提案，再明确勾选全文审核批准，分别创建批准记录、发布文档和变更记录。每步验证目标目录归属、身份与正文回读，只创建独立文档，不覆盖旧版。服务固定为 level tunning，不接受任意目录或知识库输入。

执行步骤回执保存在本地 SQLite（不含 token），同一提案同一步骤只创建一次。超时导致创建回执不确定时阻止重试；取得回执后的正文写入可在核对已有前缀后补完。再次发布会重新核对远程提案，篡改则拒绝。

仍需完成：项目索引维护、正式文档按模块建立子目录、问答独立目录、拒绝/撤回记录及认证 Agent 提交接口。当前仍是单人服务，不支持多实例并行写入。

## 云端重建恢复

- 每个成功执行步骤另建一份“服务恢复凭据”，记录操作标识、正文 SHA-256、文档定位回执和知识库标识。HMAC 密钥从应用 Client Secret 派生，密钥不会写入钉钉。凭据签名保护服务回执，不代表人为审批的数字签名。
- 老版本的本地已验证回执首次运行时核对远程正文，再补签恢复凭据。迁移前本地回执已丢失的旧记录无法证明原始内容，保留待核对，不自动放行。
- 新实例从完整扫描的签名凭据与远程正文恢复步骤；重复相同凭据可合并，冲突凭据、重复步骤文档、目录归属变化会停止恢复。正文变化、凭据缺失或不完整的步骤阻止重试，交给管理员核对。
- 删除或移出管理目录的文档不恢复；每个目录最多扫描 5000 条，超过时明确停止而非声称全部恢复。只读取已配置的四个目录，不遍历其他项目。
- 应用 Client Secret 更换后原凭据无法验签，必须在轮换前安排旧密钥验证和重签迁移。不要直接用新密钥绕过验证。
- 未点击保存的会话草稿不会恢复。批准或写入发生中断时恢复状态为待核对，当前尚未提供跨重建继续部分审批的自动执行入口。

## 当前边界

- 已移除诊断密码门槛，管理员身份仍独立核验；参与者登录不授予审核权。
- 提案绑定项目、模块、类型、原因、正文和创建范围；SHA-256 用于检测内容变化，不证明审批人身份。
- 未提交的提案与核对意见保存在会话内存，请下载留存；点击保存后提案全文独立落库。核对意见需复制进审核说明才进入批准记录。
- 已认证审核人可批准当前精确提案；未登录不提供落库按钮。登录不代表批准。
- 文件使用纯文本预览，不执行 HTML 或加载外部图片。

1. 安全设置重定向 URL 为 `https://aitest-kltimq4ak9guq9eijbhz3j.streamlit.app/`，权限包含 `Contact.User.Read` 及应用成员读取权限。
2. 点击“开始钉钉登录”，再点“打开钉钉授权页面”。保留原页面，在新标签页由本人完成登录授权。
3. 回调页面只验证并递送结果，不获得已登录会话。原页面持有仅服务会话可见的独立随机 owner secret，轮询一次性结果。
4. state 使用 256 位随机值，5 分钟过期，交换前原子占用防止重放；授权码和访问凭证不持久化或显示。返回参数清除，重复参数拒绝。
5. 用户 unionId 与应用凭据读取的已配置操作人 unionId 比对，不按昵称判断。登录身份在原会话中 30 分钟后失效，刷新需重新登录。
6. 临时登录登记仅进程内存，不适用于多实例。休眠、重启或进程迁移后请求失效，需重试，不能降级放行。当前不提供持久化登录 cookie，不跨页面恢复身份。

钉钉授权使用 `openid` 获取个人身份，未直接使用仅支持 OIDC 的 `st.login()`。若授权页返回未发布、回调不匹配或权限错误，先核对应用版本与权限，不放宽身份检查。
