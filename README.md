# AI 文档助手

Streamlit 单人试运行：企业应用只读诊断、Agent Markdown 导入、待审核提案快照及核对意见下载。

## 当前边界

- 诊断密码不是钉钉身份认证，不应交给其他 Agent 作为审批授权。
- 提案绑定项目、模块、类型、原因、正文和创建范围；SHA-256 用于检测内容变化，不证明审批人身份。
- 提案与意见仅保存在会话内存，未存入钉钉。退出、重启或断开可能丢失，请下载留存。
- 提案均处于待审核，批准与文档写入关闭。正式文档将按独立版本管理，保留旧版本。
- 文件使用纯文本预览，不执行 HTML 或加载外部图片。

## 部署

入口 `streamlit_app.py`，依赖 `requirements.txt`。按 `secrets.example.toml` 在 Streamlit Secrets 配置，禁止提交真实凭据。

## 后续接入

1. 钉钉登录：配置部署域名回调，完成授权码交换、state/会话校验和审核人白名单。
2. 持久化：提案、审核结果、执行记录分别建档到服务指定的项目时序目录。
3. 发布：审批精确提案版本，重新校验指纹，创建新版本，回读确认，再写独立变更记录和索引。
4. 恢复：远程写入前登记操作标识，超时后先核对，禁止盲目重复创建。完成并发与重启恢复后再开放多人。
5. Agent 入口：另建认证提交接口，页面按钮不等于稳定机器 API。

## 验证

`python -m unittest discover -v` 覆盖只读请求、目标校验、快照变更和大小边界。登录与远程持久化尚未验收。
